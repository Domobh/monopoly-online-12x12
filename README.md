# Monopoly 12x12 Online Full v2

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm start
```

Откройте http://localhost:3000

## Онлайн
Для игры с друзьями разместите Node.js-приложение на сервере с публичным HTTPS-адресом. После этого создайте комнату и отправьте друзьям ссылку/код.

## Добавлено
- 2–4 игрока и комнаты;
- серверная синхронизация;
- покупка;
- аукцион;
- торговля деньгами и собственностью;
- дома и отели;
- продажа улучшений;
- залог и выкуп;
- железные дороги с изменяемой арендой;
- тюрьма и три дубля;
- двойные броски дают дополнительный ход;
- шанс/общественная казна;
- налоги;
- банкротство и победитель;
- индикация подключения игроков;
- сохранение комнаты в памяти сервера на время его работы.

Это самостоятельная Monopoly-подобная игра, а не копия официальной игры и её оригинальной графики.
